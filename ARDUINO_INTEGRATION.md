
# Integrating Arduino (Uno) and ESP32 with IoT Guardian

This document provides guidance and example code for a two-MCU setup:
1.  An **Arduino Uno** (or similar) reads sensors, controls actuators, and handles local logic (keypad, SMS).
2.  An **ESP32** acts as a communication bridge, providing WiFi and BLE capabilities. It receives data from the Arduino via Serial, sends it to the IoT Guardian Next.js application API, fetches commands from the API, and relays those commands back to the Arduino.

## Communication Flow

Sensors/Keypad/SIM900 -> Arduino Uno -> Serial TX/RX -> ESP32 (Serial2 RX/TX) -> WiFi -> IoT Guardian API
IoT Guardian API -> WiFi -> ESP32 -> Serial2 TX/RX -> Arduino Uno -> Actuators/LCD

## Next.js API Endpoints

### 1. Receiving Sensor Data
*   **Endpoint**: `/api/sensor-data`
*   **Method**: `POST`
*   **Expected JSON Payload from ESP32**:
    ```json
    {
      "deviceId": "your_esp32_unique_device_id", // e.g., "esp32-living-room-01"
      "temperature": 25.5, // Optional, in Celsius
      "humidity": 60.2,   // Optional, in %
      "waterLeak": false, // Optional, boolean derived from Arduino's water sensor
      "timestamp": "2023-10-27T10:30:00Z" // ISO 8601 format (YYYY-MM-DDTHH:mm:ssZ), generated by ESP32
    }
    ```

### 2. Fetching Device Commands
*   **Endpoint**: `/api/device-command/[deviceId]` (replace `[deviceId]` with your ESP32's device ID)
*   **Method**: `GET`
*   **Example Response from Server (if command exists)**:
    ```json
    {
      "command": "OFF", // or "ON"
      "timestamp": "2023-10-28T12:00:00Z",
      "parameters": {} // Optional additional parameters
    }
    ```
*   **Example Response from Server (no command)**:
    ```json
    {
      "message": "No pending commands for device your_device_id."
    }
    ```

## ESP32 Setup and Code Example

The ESP32 will:
*   Connect to WiFi.
*   Initialize BLE (as per your original code, for potential direct control).
*   Listen for data from the Arduino Uno via Serial2.
*   Parse the JSON data received from the Arduino.
*   Format a new JSON payload according to the IoT Guardian API specification and POST it.
*   Periodically GET commands from the IoT Guardian API.
*   Parse the command received from the API and send it to the Arduino Uno via Serial2.

**Hardware Connections (ESP32 and Arduino Uno):**
*   ESP32 `TX2` (GPIO17 by default for `Serial2`) -> Arduino Uno `RX` (Pin 0 or other if using SoftwareSerial on Uno)
*   ESP32 `RX2` (GPIO16 by default for `Serial2`) -> Arduino Uno `TX` (Pin 1 or other if using SoftwareSerial on Uno)
*   Connect `GND` of ESP32 to `GND` of Arduino Uno.

**ESP32 Libraries Needed:**
*   `WiFi.h`
*   `HTTPClient.h`
*   `ArduinoJson.h` (by Benoit Blanchon)
*   `BLEDevice.h`, `BLEUtils.h`, `BLEServer.h`, `BLE2902.h` (if using BLE)
*   `time.h`

```cpp
void connectToWiFi() {
  Serial.print("Connecting to WiFi: ");
  Serial.println(ssid);
  WiFi.begin(ssid, password);
  int attemptCount = 0;
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
    attemptCount++;
    if (attemptCount > 30) { // Timeout after 15 seconds
        Serial.println("\nFailed to connect to WiFi. Retrying...");
        WiFi.disconnect(); // Clean up previous attempt
        delay(1000);
        WiFi.begin(ssid, password); // Retry connection
        attemptCount = 0; // Reset counter
    }
  }
  Serial.println("\nWiFi connected!");
  Serial.print("IP Address: ");
  Serial.println(WiFi.localIP());
}

void configureTime() {
    Serial.print("Configuring time from NTP server");
    configTime(0, 0, "pool.ntp.org", "time.nist.gov"); // UTC time
    time_t now = time(nullptr);
    int attempts = 0;
    while (now < 8 * 3600 * 2 && attempts < 20) { // Wait for a valid time (greater than 2 hours epoch)
        delay(500);
        Serial.print(".");
        now = time(nullptr);
        attempts++;
    }
    if (attempts >= 20) {
        Serial.println("\nFailed to sync time with NTP server.");
    } else {
        Serial.println("\nTime synchronized with NTP server.");
    }
}

// Sends formatted sensor data to the IoT Guardian Web API
void sendDataToWebApp(float temp, float hum, bool leak) {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    
    Serial.print("[HTTP-TX] Connecting to: ");
    Serial.println(sensorDataEndpoint);

    if (!http.begin(sensorDataEndpoint)) { 
      Serial.println("[HTTP-TX] Unable to connect to endpoint.");
      return;
    }
    http.addHeader("Content-Type", "application/json");

    StaticJsonDocument<256> doc; // Use StaticJsonDocument for predictable memory usage
    doc["deviceId"] = esp32DeviceId;
    if (!isnan(temp)) doc["temperature"] = temp; else doc["temperature"] = nullptr; // Send null if NaN
    if (!isnan(hum)) doc["humidity"] = hum; else doc["humidity"] = nullptr; // Send null if NaN
    doc["waterLeak"] = leak;

    time_t now_time;
    time(&now_time);
    char timestamp[30];
    // Ensure time is synced before formatting
    if (now_time > 8 * 3600 * 2) { // Check if time is reasonably synced
        strftime(timestamp, sizeof(timestamp), "%Y-%m-%dT%H:%M:%SZ", gmtime(&now_time));
        doc["timestamp"] = timestamp;
    } else {
        doc["timestamp"] = "TIME_NOT_SYNCED"; // Or handle this case appropriately
        Serial.println("[HTTP-TX] Warning: Time not synced, sending placeholder timestamp.");
    }
    
    String requestBody;
    serializeJson(doc, requestBody);
    
    Serial.print("[HTTP-TX] POST JSON: ");
    Serial.println(requestBody);

    int httpCode = http.POST(requestBody);

    if (httpCode > 0) {
      Serial.printf("[HTTP-TX] POST... code: %d\n", httpCode);
      String payload = http.getString();
      Serial.println("[HTTP-TX] Received response:");
      Serial.println(payload);
    } else {
      Serial.printf("[HTTP-TX] POST... failed, error: %s\n", http.errorToString(httpCode).c_str());
    }
    http.end();
  } else {
    Serial.println("[HTTP-TX] WiFi Disconnected - Cannot send sensor data");
  }
}

// Fetches commands from the IoT Guardian Web API and sends them to Arduino
void fetchAndProcessCommands() {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    String fullCommandUrl = commandEndpointBase + String(esp32DeviceId);

    Serial.print("[HTTP-RX] Checking for commands at: ");
    Serial.println(fullCommandUrl);

    if (!http.begin(fullCommandUrl)) {
      Serial.println("[HTTP-RX] Unable to connect to command endpoint.");
      return;
    }

    int httpCode = http.GET();
    if (httpCode > 0) {
      Serial.printf("[HTTP-RX] GET... code: %d\n", httpCode);
      String payload = http.getString();
      Serial.println("[HTTP-RX] Received command payload: " + payload);

      StaticJsonDocument<128> doc; // Adjust size as needed for command JSON
      DeserializationError error = deserializeJson(doc, payload);

      if (error) {
        Serial.print("[HTTP-RX] deserializeJson() failed for command: ");
        Serial.println(error.c_str());
        // Check if it's the "No pending commands" message, which is not an error here.
        if (payload.indexOf("No pending commands") == -1 && payload.indexOf("Device ID is required") == -1) {
             // It's a real parsing error or an unexpected server message.
        }
      } else {
        if (doc.containsKey("command")) {
          const char* command = doc["command"]; // "ON" or "OFF"
          if (command) {
            Serial.print("[COMMAND] Received command from server: ");
            Serial.println(command);
            // Send the raw command (e.g., "ON" or "OFF") to Arduino
            ArduinoSerial.println(command); 
            Serial.println("[COMMAND] Sent to Arduino: " + String(command));
            // Note: The API command is not automatically deleted on GET.
            // For a robust system, the device might send an acknowledgment POST to clear the command.
          }
        } else if (doc.containsKey("message") && payload.indexOf("No pending commands") != -1) {
            Serial.println("[COMMAND] No pending commands from server.");
        } else {
            Serial.println("[COMMAND] Received JSON from server, but no 'command' field found.");
        }
      }
    } else {
      Serial.printf("[HTTP-RX] GET... failed, error: %s\n", http.errorToString(httpCode).c_str());
    }
    http.end();
  } else {
    Serial.println("[HTTP-RX] WiFi Disconnected - Cannot check for commands");
  }
}


void setup() {
  Serial.begin(115200);
  delay(1000); 

  // Initialize Serial2 for communication with Arduino
  ArduinoSerial.begin(9600, SERIAL_8N1, ARDUINO_RX_PIN, ARDUINO_TX_PIN);
  Serial.println("Serial2 for Arduino communication initialized.");

  connectToWiFi();
  
  if (WiFi.status() == WL_CONNECTED) {
    configureTime(); // Configure NTP time
  }

  // --- BLE Setup (from your original code) ---
  Serial.println("Initializing BLE...");
  BLEDevice::init("ESP32_IoT_Guardian_Node"); // Changed name slightly
  BLEServer *pServer = BLEDevice::createServer();
  pServer->setCallbacks(new MyServerCallbacks());
  BLEService *pService = pServer->createService(SERVICE_UUID);
  pCharacteristic_BLE = pService->createCharacteristic(
                      CHARACTERISTIC_UUID,
                      BLECharacteristic::PROPERTY_READ |
                      BLECharacteristic::PROPERTY_WRITE |
                      BLECharacteristic::PROPERTY_NOTIFY // Added Notify for sending data to BLE client
                    );
  pCharacteristic_BLE->addDescriptor(new BLE2902()); // For notifications
  pCharacteristic_BLE->setCallbacks(new MyCharacteristicCallbacks()); // For receiving data from BLE client
  pCharacteristic_BLE->setValue("ESP32 Ready");
  pService->start();
  BLEAdvertising *pAdvertising = BLEDevice::getAdvertising();
  pAdvertising->addServiceUUID(SERVICE_UUID);
  pAdvertising->setScanResponse(true);
  pAdvertising->setMinPreferred(0x06);  // functions that help with iPhone connections issue
  pAdvertising->setMinPreferred(0x12);
  BLEDevice::startAdvertising();
  Serial.println("BLE Service Started. Advertising...");
  
  Serial.println("ESP32 Setup complete. Device ready.");
}

void loop() {
  unsigned long currentTime = millis();

  // 1. Read data from Arduino via Serial2
  if (ArduinoSerial.available()) {
    String arduinoDataJson = ArduinoSerial.readStringUntil('\n');
    arduinoDataJson.trim();
    Serial.print("Received from Arduino: ");
    Serial.println(arduinoDataJson);

    // Parse Arduino's JSON
    StaticJsonDocument<256> doc; // Adjust size based on Arduino's JSON
    DeserializationError error = deserializeJson(doc, arduinoDataJson);

    if (error) {
      Serial.print("deserializeJson() failed (Arduino data): ");
      Serial.println(error.c_str());
    } else {
      // Extract values needed for the web API
      float temp = doc["temperature"] | NAN; // Default to NAN if missing
      float hum = doc["humidity"] | NAN;    // Default to NAN if missing
      int waterPercent = doc["water"] | 0;  // Default to 0 if missing
      // You might want to read "status" (ON/OFF) from Arduino for local decisions on ESP32 if needed

      // Derive waterLeak boolean (e.g., if waterPercent > 60, it's a leak)
      bool leak = (waterPercent > 60); 

      // Send formatted data to Web API periodically
      if (currentTime - lastDataSendTime >= dataSendInterval) {
        lastDataSendTime = currentTime;
        Serial.printf("Sending to Web API: Temp=%.1f, Hum=%.1f, Leak=%s\n", temp, hum, leak ? "true" : "false");
        sendDataToWebApp(temp, hum, leak);
      }

      // If BLE device is connected, you might want to send some data to it too
      if (bleDeviceConnected) {
        // Example: Send a summary or the raw Arduino JSON via BLE
        // For instance, sending the raw Arduino JSON string:
        // pCharacteristic_BLE->setValue(arduinoDataJson.c_str());
        // pCharacteristic_BLE->notify();
        // Or a custom summary:
        String bleSummary = "T:" + String(temp,1) + " H:" + String(hum,1) + " L:" + (leak ? "1" : "0");
        pCharacteristic_BLE->setValue(bleSummary.c_str());
        pCharacteristic_BLE->notify();
        Serial.println("Sent to BLE: " + bleSummary);
      }
    }
  }

  // 2. Check for commands from Web API periodically
  if (currentTime - lastCommandFetchTime >= commandFetchInterval) {
    lastCommandFetchTime = currentTime;
    fetchAndProcessCommands();
  }
  
  // Small delay to prevent busy-looping if no serial data
  delay(10); 
}
```

```cpp
// arduino_uno_code_example.cpp
#include <Keypad.h>
#include <LiquidCrystal_I2C.h>
#include <DHT.h>
// If Serial (pins 0,1) is used for ESP32, you won't be able to use Serial Monitor easily.
// If using other pins for ESP32 communication, use SoftwareSerial here.
// For this example, we assume ESP32 is connected to Arduino's Hardware Serial (pins 0,1)
// and SIM900 uses SoftwareSerial.

// DHT11

#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

#include <SoftwareSerial.h>
SoftwareSerial sim900(8, 7); // RX, TX for SIM900

// Pins
const int relayPin = 2;
const int buzzerPin = 6;
const int waterSensorPin = A3;

// Password
const String password = "1234";
String inputPassword = "";

// Keypad 4x4
const byte ROWS = 4;
const byte COLS = 4;
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}

Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void loop() {
  // checkIncomingSMS(); // Keep if using SMS features

  // Listen for commands from ESP32
  if (Serial.available()) {
    String cmdFromESP = Serial.readStringUntil('\n');
    cmdFromESP.trim();
    Serial.print("Received from ESP32: "); Serial.println(cmdFromESP);

    if (cmdFromESP.equalsIgnoreCase("ON")) {
      lcd.clear();
      lcd.print("CMD: ON (Web)");
      digitalWrite(relayPin, HIGH);
      machineOn = true;
      delay(1000);
      lcd.clear();
      lcd.print("Monitoring...");
      // sendSMS("System turned ON via Web App"); // Optional SMS
    } else if (cmdFromESP.equalsIgnoreCase("OFF")) {
      lcd.clear();
      lcd.print("CMD: OFF (Web)");
      digitalWrite(relayPin, LOW);
      machineOn = false;
      inputPassword = ""; // Reset password state
      delay(1000);
      lcd.clear();
      lcd.print("Enter Password:");
      // sendSMS("System turned OFF via Web App"); // Optional SMS
    }
    // You can add more commands here if needed, e.g., for bleFeatureEnabled
    // else if (cmdFromESP.equalsIgnoreCase("ble=on")) { bleFeatureEnabled = true; }
    // else if (cmdFromESP.equalsIgnoreCase("ble=off")) { bleFeatureEnabled = false; }
  }

  // Keypad input for password
  char key = keypad.getKey();
  if (key) {
    handleKeypadInput(key);
  }

  if (machineOn) {
    // Only send data if machine is ON
    if (millis() - lastDataSentToESPTime > dataSendToESPInterval) {
      float t = dht.readTemperature();
      float h = dht.readHumidity();
      int waterRaw = analogRead(waterSensorPin);
      // Convert raw water sensor reading to a percentage or relevant metric
      // This mapping depends on your sensor. Example:
      int waterPercent = map(waterRaw, 0, 1023, 0, 100); // Adjust 1023 if sensor max is different
      if (waterRaw < 50) waterPercent = 0; // Example: if very low, consider it 0%
      if (waterRaw > 900) waterPercent = 100; // Example: if very high, cap at 100%

      // Update LCD
      lcd.clear();
      lcd.setCursor(0, 0);
      lcd.print("T:"); lcd.print(isnan(t) ? "Err" : String(t,1)); 
      lcd.print(" H:"); lcd.print(isnan(h) ? "Err" : String(h,1));
      lcd.setCursor(0, 1);
      lcd.print("Water: "); lcd.print(waterPercent); lcd.print("%");

      // Prepare JSON data for ESP32
      String jsonData = "{";
      jsonData += "\"temperature\":" + (isnan(t) ? "null" : String(t, 1)) + ",";
      jsonData += "\"humidity\":" + (isnan(h) ? "null" : String(h, 1)) + ",";
      jsonData += "\"water\":" + String(waterPercent) + ","; // ESP32 will convert this to boolean "waterLeak"
      jsonData += "\"status\":\"ON\""; // Machine is ON
      // Optionally add ble and waterLeakSensorEnabled status if ESP32 needs them for some reason
      // jsonData += ",\"ble_enabled\":" + String(bleFeatureEnabled ? "true" : "false") + ",";
      // jsonData += ",\"water_sensor_enabled\":" + String(waterLeakSensorEnabled ? "true" : "false");
      jsonData += "}";
      Serial.println(jsonData); // Send JSON to ESP32
      lastDataSentToESPTime = millis();
      
      // Local water leak detection and shutdown (as per your original logic)
      if (waterLeakSensorEnabled && waterRaw > 600) { // Adjust 600 threshold as needed
        handleLocalEmergency("Water Leak!", "ALERT: Water leak! System OFF");
        return; // Stop further processing in loop until reset
      }

      // Local high temperature detection and shutdown
      if (!isnan(t) && t > 35) { // Adjust 35C threshold as needed
        handleLocalEmergency("High Temp!", "ALERT: High temp! System OFF");
        return; // Stop further processing in loop until reset
      }
    }
  } else { // Machine is OFF
    if (millis() - lastDataSentToESPTime > dataSendToESPInterval) { // Still send status periodically
        String jsonData = "{\"status\":\"OFF\"}"; // Simplified JSON when OFF
        Serial.println(jsonData);
        lastDataSentToESPTime = millis();
        if (inputPassword.length() == 0 && !lcd.getCursorCol() && !lcd.getCursorRow()){ // Check if on password screen
            lcd.setCursor(0,0);
            lcd.print("Enter Password:");
        }
    }
  }
  delay(100); // Short delay
}

void handleKeypadInput(char key) {
  if (!machineOn) { // Only accept password input if machine is OFF
    if (key == '#') {
      if (inputPassword == password) {
        lcd.clear();
        lcd.print("Access Granted!");
        digitalWrite(relayPin, HIGH);
        machineOn = true;
        delay(1000);
        lcd.clear();
        lcd.print("Monitoring...");
        // sendSMS("System activated via Keypad"); // Optional
      } else {
        lcd.clear();
        lcd.print("Wrong Code!");
        digitalWrite(buzzerPin, HIGH);
        delay(500);
        digitalWrite(buzzerPin, LOW);
        // sendSMS("Security: Wrong password attempt!"); //Optional
      }
      inputPassword = ""; // Reset password input
      delay(1000);
      if (!machineOn) { // If still off (wrong password)
        lcd.clear();
        lcd.print("Enter Password:");
      }
    } else if (key == '*') {
      inputPassword = "";
      lcd.clear();
      lcd.setCursor(0, 1);
      lcd.print("Password Cleared");
      delay(1000);
      lcd.clear();
      lcd.print("Enter Password:");
    } else if (inputPassword.length() < 8) { // Limit password input length
      inputPassword += key;
      lcd.setCursor(0, 1);
      for (int i = 0; i < inputPassword.length(); i++) {
        lcd.print("*");
      }
    }
  } else if (key == 'D') { // Example: Use 'D' key to turn OFF if machine is ON
      lcd.clear();
      lcd.print("CMD: OFF (Key)");
      digitalWrite(relayPin, LOW);
      machineOn = false;
      inputPassword = "";
      delay(1000);
      lcd.clear();
      lcd.print("Enter Password:");
      // sendSMS("System turned OFF via Keypad"); // Optional
  }
}

void handleLocalEmergency(String lcdMessage, String smsMessage) {
  lcd.clear();
  lcd.print(lcdMessage);
  digitalWrite(buzzerPin, HIGH);
  digitalWrite(relayPin, LOW); // Turn off machine
  
  // Send JSON status to ESP32 immediately
  String jsonData = "{";
  jsonData += "\"temperature\":" + String(dht.readTemperature(),1) + ","; // Send current temp
  jsonData += "\"humidity\":" + String(dht.readHumidity(),1) + ",";     // Send current hum
  jsonData += "\"water\":" + String(map(analogRead(waterSensorPin), 0, 1023, 0, 100)) + ",";
  jsonData += "\"status\":\"OFF_EMERGENCY\""; // Special status
  jsonData += "}";
  Serial.println(jsonData);

  // sendSMS(smsMessage); // Optional SMS
  
  delay(3000); // Buzzer on for 3 seconds
  digitalWrite(buzzerPin, LOW);
  
  machineOn = false;
  inputPassword = ""; // Require password again
  lcd.clear();
  lcd.print("Enter Password:");
}
```

## Important Considerations

*   **Replace Placeholders**: Carefully replace `YOUR_WIFI_SSID`, `YOUR_WIFI_PASSWORD`, `YOUR_NEXTJS_APP_IP_OR_DOMAIN:PORT`, and `esp32-main-controller-01` in the ESP32 code with your actual values.
*   **IP Address for Local Development**: When running the Next.js app locally, the `serverBaseUrl` in the ESP32 code must use the **local IP address** of the computer running the Next.js server, not `localhost`.
*   **Arduino Serial**: The Arduino Uno has one main hardware serial port (`Serial`) on pins 0 (RX) and 1 (TX). If you use this for USB programming/debugging, you'll need to use `SoftwareSerial` for communication with the ESP32 on different pins, or disconnect the USB when the Arduino is communicating with the ESP32. The ESP32 code provided uses its `Serial2` (GPIO 16, 17). Adjust pins and `Serial`/`ArduinoSerial` objects as per your hardware connections.
*   **JSON Parsing & Memory**: `StaticJsonDocument` is used in the ESP32 code for more predictable memory usage compared to `DynamicJsonDocument`. Adjust the sizes (e.g., `StaticJsonDocument<256>`) based on the actual size of your JSON payloads.
*   **Error Handling**: The provided code includes basic error handling for HTTP requests and JSON parsing. You might want to expand on this for a more robust system (e.g., retry mechanisms).
*   **Command Acknowledgement**: The current API for commands (`/api/device-command`) does not automatically clear a command once it's fetched by the ESP32. If the ESP32 fetches multiple times before the command is updated on the server, it might receive the same command repeatedly. For a more robust system, you could implement a mechanism where the ESP32 sends an "acknowledgement" POST request to a new endpoint after processing a command, signaling the server to clear it.
*   **Security**: For production, always use HTTPS for API communication if your ESP32 and network support it. Consider API keys or other authentication methods for the API endpoints.
